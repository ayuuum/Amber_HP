# 調達向け・AI導入事例比較チェックシート

複数ベンダー・事例を横並びで評価し、比較可能な表にしてください。

## 機能と適用範囲

- [ ] 対象業務と非対象業務が明記されている
- [ ] 人の承認が必要な操作の有無を確認した
- [ ] 既存システム連携（API・SSO等）の実績形式が同じ粒度で書かれている

## データとセキュリティ

- [ ] 学習データへの利用可否・オプトアウト条件を確認した
- [ ] データ保存リージョンと暗号化・バックアップ方針を揃えて比較した
- [ ] 個人情報・機密情報を入力した場合の処理フローが説明されている

## 契約とコスト

- [ ] 初期費用・ランニング・従量課金の内訳が同じ期間で提示されている
- [ ] SLA・サポート時間・障害連絡窓口が記載されている
- [ ] 契約終了時のデータエクスポートと削除方法を確認した

## 運用と実績

- [ ] 導入期間の目安と必要な社内リソース（人日）が示されている
- [ ] 参考事例の業種・規模・導入規模（ユーザー数等）が近いか検討した
- [ ] トレーニング・ドキュメント・管理者向け機能の有無を比較した

## 評価記録

- [ ] 必須要件／望ましい要件を事前に重み付けした
- [ ] デモまたはPoCで確認した項目にチェック日と担当を付けた
- [ ] 未確認項目は「条件付き」として発注判断に反映した
