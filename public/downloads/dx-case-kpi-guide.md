# DX事例のKPI見方ガイド

事例の数字は「その会社・その条件」での結果です。自社判断のために、次を確認してください。

## 数字の出どころ

- [ ] 指標の定義（分子・分母・対象業務）が記載されているか
- [ ] 測定開始前のベースラインが示されているか
- [ ] 効果が出るまでの期間（導入〜定着）が分かるか

## 比較の公平性

- [ ] 業界・規模・地域が自社と大きく異ならないか検討した
- [ ] 同時に進めた他施策（組織変更・値下げ等）の影響が分離されているか
- [ ] 成功事例だけでなく、うまくいかなかった点の記述があるか

## 自社への転用

- [ ] 同種の業務・データ・システムが自社にも存在するか
- [ ] 再現に必要な前提（権限・マスタ品質・現場合意）をリスト化した
- [ ] 真似るのは「数字」ではなく「プロセスと体制」に置き換えた

## 社内合意用メモ

- [ ] 参考にしたい点を3行以内で書いた
- [ ] 自社で最初に測る指標（時間・件数・エラー等）を1〜2個に絞った
- [ ] 測定方法と担当を決めてからPoCに進む合意を得た

## 注意

- [ ] 公開情報にない詳細数値を推測で補完していない
- [ ] ベンダー資料の宣伝文句と実測値を区別した
