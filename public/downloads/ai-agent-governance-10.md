# AIエージェントガバナンス10項目チェック

運用開始前と四半期ごとに、次の10項目を担当者が確認してください。

1. **利用目的の定義** — [ ] 許可する業務範囲と禁止事項を文書化した  
2. **データ分類** — [ ] 入力・出力に載せてよい情報区分（公開／社内限／機密）を決めた  
3. **モデル・ツール選定** — [ ] 利用サービス一覧と契約・データ保持条件を管理している  
4. **身份・権限** — [ ] ユーザーごと・エージェントごとに最小権限を設定した  
5. **人間による承認** — [ ] 外部送信・購買・個人情報更新など高リスク操作に承認を必須にした  
6. **ログと監査** — [ ] 誰が・いつ・何を実行したか追跡できる  
7. **品質評価** — [ ] 定期のサンプルレビューと修正フローがある  
8. **インシデント対応** — [ ] 誤回答・情報漏えい疑いの連絡先と初動手順がある  
9. **教育** — [ ] 利用者向けに安全なプロンプトと禁止例を共有した  
10. **見直し** — [ ] ポリシー更新日と次回レビュー日を記録した  

## 実施メモ

- [ ] 未達項目にオーナーと期限を付けた  
- [ ] 経営・情シス・現場代表の3者で結果を共有した
