# 現場自動化パイロット開始前チェックリスト

パイロットは「小さく始めて学ぶ」フェーズです。着手前に次を確認してください。

## 対象業務の選定

- [ ] 頻度・件数・所要時間が把握できている
- [ ] 入力・出力・判断基準が文章またはフローで説明できる
- [ ] 例外処理の代表例を3件以上挙げられる
- [ ] 現場リーダーが「この業務なら試したい」と合意している

## 体制と役割

- [ ] 現場オーナー（意思決定）と実務担当が決まっている
- [ ] IT・情シスとの連絡窓口が一本化されている
- [ ] パイロット期間（目安）と週次の振り返り日がカレンダーに入っている

## 計測と成功条件

- [ ] 現状のベースライン（時間・手戻り・問い合わせ件数など）を記録した
- [ ] パイロット成功の定義を「現場が使い続ける」など行動ベースで書いた
- [ ] 本番移行の判断基準（誰が・いつ・何を見るか）を決めた

## リスクと安全

- [ ] 個人情報・機密情報の取り扱いルールを確認した
- [ ] 自動化失敗時の手作業フォールバック手順がある
- [ ] 変更内容を関係者に事前共有した

## 次のアクション

- [ ] 未チェック項目ごとに担当と期限を1行メモした
- [ ] 関連記事で用語と進め方をチームで共有した
