# AI導入・現場定着チェックリスト

技術導入と同時に「使われる仕組み」を用意すると、定着が進みやすくなります。

## 準備（導入前）

- [ ] 解決したい業務課題を現場の言葉で1文にした
- [ ] チャンピオン（現場の推進役）を指名した
- [ ] 利用ルール（入力してよい情報・禁止例）を共有した

## 展開（初期2〜4週）

- [ ] 最初の利用者グループを限定し、ユースケースを3件以内に絞った
- [ ] 操作手順とよくある質問を1ページにまとめた
- [ ] 週次で15分の振り返り（うまくいった／困った）を実施した

## サポート

- [ ] 問い合わせ窓口（チャット・メール等）と対応時間帯を決めた
- [ ] 情シス・ベンダー・現場の役割分担を明示した
- [ ] 不具合と「使い方」の切り分け基準を決めた

## 改善と拡大

- [ ] 利用ログやヒアリングからボトルネックを1つ特定した
- [ ] 次に広げる部署・業務の条件（成功パターン）を書いた
- [ ] 経営層へ定着状況を短く報告するサイクルを入れた

## クロージング

- [ ] 定着の判断（継続利用・手順改定・中止）をデータと現場声で行った
- [ ] 関連記事のチェンジ管理の要点をチームで再確認した
