# 業務AIエージェント適性チェックリスト

エージェントは「判断と手順が説明できる業務」で力を発揮しやすいです。導入前に以下を確認してください。

## タスクの性質

- [ ] 入力・出力が明確で、完了条件を言語化できる
- [ ] 手順の大半がデジタル上のツール操作で完結する
- [ ] 致命的な誤りが起きた場合の影響範囲を把握している

## データと根拠

- [ ] 参照すべき社内ルール・マスタ・過去事例にアクセスできる（または整備計画がある）
- [ ] 回答に引用元を示す必要がある場合、その形式を決めている
- [ ] 学習不要で都度参照する方式（RAG等）で足りるか検討した

## 権限とガードレール

- [ ] エージェントが実行してよい操作（読取のみ／下書き／実行）を分離した
- [ ] 人の承認が必須なステップをフローに組み込んだ
- [ ] ログ（プロンプト・ツール呼び出し・結果）の保存方針がある

## 評価と改善

- [ ] 正解例・禁止例を少数でもテストケースとして用意した
- [ ] 現場担当が週次で品質をレビューする時間を確保した
- [ ] 不適合時のエスカレーション先を決めた

## Go／No-Go

- [ ] 未チェックが「データ整備」「権限設計」に集中していないか確認した
- [ ] まずは単一業務・限定ユーザーでのパイロットに合意した
